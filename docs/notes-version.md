## Nouveautés

- **Edge en secours sous Windows.** Si Google Chrome n'est pas installé ou ne se lance pas,
  la connexion passe par Microsoft Edge, présent sur tous les Windows. Chrome n'est donc plus
  un prérequis sous Windows. Sur Mac, Chrome reste nécessaire.

## Rappel de la version 1.2

- Statuts lus dans les listes de lectures des séances, nouveau statut « Pour aller plus loin »,
  sous-sections Moodle rattachées à leur séance.
- Bouton Annuler, pastille de nouveautés par cours, notification du système en mode automatique.

## À savoir

- Les fichiers déjà rangés ne sont jamais déplacés : seuls les nouveaux suivent les nouvelles
  règles.
- Les exécutables ne sont pas signés : Windows et macOS afficheront un avertissement au premier
  lancement (voir le README).
